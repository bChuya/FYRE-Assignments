# FYRE-Assignments

This repository contains a collection of projects and activities focused on environmental monitoring, automation, and programming practice.

## Folder Overview

### MoistureSensor
This folder contains the programs and scripts used to collect data from the moisture sensor and send the information to a Google Sheet for recording and analysis.

### PlantWaterer
This folder contains a prototype project for a smart plant-covering system. It detects changes in humidity and turns on a green indicator light when the environment is humid, suggesting that rain may be coming. The moisture sensor continuously checks for water, and if moisture is detected, a servo motor deploys a cover or awning to protect the plant.

### ProgrammingActivites
This folder contains the programming activities and exercises completed throughout the course.

### Reflections
This folder contains reflection notes and personal responses documenting learning progress, observations, and experiences gained from the projects.

## Summary
These projects combine sensors, automation, and programming to explore how technology can monitor environmental conditions and respond intelligently to changes.
